Put your publication files in this folder.

Recommended examples:
  paper-2026-short-title.pdf
  conference-2025-short-title.pdf
  paper-2026-short-title.bib
  conference-2025-slides.pdf

Then use the matching path in _data/publications.yml, for example:

  links:
    paper: "/files/publications/paper-2026-short-title.pdf"
    slides: "/files/publications/conference-2025-slides.pdf"
    bibtex: "/files/publications/paper-2026-short-title.bib"

Do not use spaces in file names. Use lowercase letters and hyphens.
